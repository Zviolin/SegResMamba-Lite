## 二、核心架构

```
输入 [B, 4, 64, 64, 64]
    │
    ▼
┌─────────────────────────────────────────────────┐
│  input_proj: ConvBlock(4→8)                      │
│  输出: [B, 8, 64, 64, 64]                        │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  enc1: ConvBlock + ResBlock + MaxPool            │
│  输出: [B, 16, 32, 32, 32]  ← skip1              │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  enc2: ConvBlock + ResBlock + MaxPool            │
│  输出: [B, 32, 16, 16, 16]  ← skip2              │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  bottleneck: ConvBlock + ResBlock                │
│  输出: [B, 64, 8, 8, 8]                          │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  dec2: ConvTranspose3d + Cat + ConvBlock + ResBlock│
│  输出: [B, 32, 16, 16, 16]                       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  dec1: ConvTranspose3d + Cat + ConvBlock + ResBlock│
│  输出: [B, 16, 32, 32, 32]                       │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  output_proj: Conv3d(1) → [B, 4, 64, 64, 64]    │
└─────────────────────────────────────────────────┘
```

### 关键模块

**ConvBlock**: Conv3d → BatchNorm3d → SiLU

**ResBlock**:
```
输入 x
    ↓ Conv3d(3×3×3) → BN → SiLU
    ↓ Conv3d(3×3×3) → BN
    ↓ Dropout
    ↓ + x (残差连接)
    ↓ SiLU
输出
```

### 设计特点

- **2 层下采样**: 仅 enc1 + enc2，结构极简
- **拼接 Skip Connection**: 保留完整空间信息
- **转置卷积上采样**: 可学习的上采样
- **ResBlock**: 标准残差连接，稳定训练
- **SiLU 激活**: 平滑梯度

## 五、实验结果

| 指标 | WT | TC | ET |
|------|------|------|------|
| **全局 Dice** | 0.9109 | 0.8829 | 0.8376 |
| **全局 HD95 (mm)** | 5.49 | 4.80 | 4.09 |
| **LW Dice WT** | 0.8509 | 0.8384 | 0.7691 |
| **LW HD95 WT (mm)** | 30.47 | 27.29 | 41.28 |

### 结果分析

- **LW Dice 优秀**: 病灶级别分割精度高
- **LW HD95 异常高**: 可能存在假阳性检测问题
- **全局 HD95 良好**: 整体边界重建质量不错

## 八、定位与意义

VMUNet 在本项目中作为 **轻量级基线**：

1. **参数量适中**: ~0.8M，比 SegResNet 小很多
2. **训练速度快**: 结构简单，推理高效
3. **LW Dice 优秀**: 病灶检测能力强
4. **对比参照**: 与 Mamba 模型对比，展示轻量级 CNN 的能力边界
