# 脑肿瘤 MRI 分割 APP —— 需求与可行性分析文档

> 版本：v1.1 · 日期：2026-09-29
> 范围：在**已完成的移动端网页**（前期工作）基础上，新增两大功能并打包为移动端 APP。

---

## 1. 前期已完成工作（已有基础，非本期需求）

原有移动端网页为**已交付成果**，是本次开发的基座。本期不重复开发以下功能，仅直接复用：

- **离线分割推理**：ONNX Runtime Web 本地跑 SegResNet-Mamba 模型，支持 BraTS 4 模态（T1n/T1c/T2w/T2f），无需联网（`src/services/inference/offline/*`）。
- **NIfTI 解析与三平面可视化**：`niftiParser.ts` 解析二进制，MPR 三平面（轴/冠/矢）Canvas 渲染（`MPRViewer` / `PlaneViewer` / `MobileTriView`），移动端响应式布局。
- **肿瘤量化统计**：`calculateTumorStatistics` 已算出 NCR / ED / ET 的体素数、体积、受影响切片范围。
- **历史记录本地存储**：`localHistory.ts` / `historyGateway.ts`。
- **统一推理接口**：`InferenceProvider` 抽象在线 / 离线两种引擎。
- **PDF 库就绪**：`jspdf` 已在依赖中。
- **屏幕端量化报告面板**：`AnalysisReport.tsx` 已在右侧面板展示量化指标（非 PDF 导出）。

---

## 2. 本期目标与范围

在已有网页基座上**新增**以下内容，产物为可安装的 iOS/Android APP：

- **F1 智能报告与解读（主线）**：自动生成结构化 PDF 报告 + 体积阈值自动解读 + 术语科普卡片。
- **F2 不确定性热图 / 可信 AI（附加，与报告结合）**：复用模型输出的概率，把"把握大小"画成热力图叠加到影像，报告附不确定性图。
- **F3 APP 化与导出适配（交付形态）**：Capacitor 打包原生壳；将网页端文件导出逻辑迁移到原生 API。

## 3. 功能需求（本期新增）

### F1 智能报告与解读

| 编号 | 功能 | 说明 |
|---|---|---|
| FR1.1 | 结构化 PDF 报告导出 | 在已有 `AnalysisReport` 面板加「导出 PDF」按钮，用 `jspdf` 输出：总体四宫格 + 区域分布表 + 三平面缩略图。**复用** `calculateTumorStatistics` 与 `formatVolume`。 |
| FR1.2 | 自动解读规则引擎 | 读取量化结果，结合**开发者基于文献调研整理的临床阈值规则**生成自然语言解读（例："ET 占比偏高，建议结合增强序列复核"）。规则附论文出处、可溯源；纯前端、**不依赖外部 AI/API**；报告须附"结果由算法按规则自动生成、非临床诊断"免责声明。 |
| FR1.3 | 术语科普卡片 | 对 NCR / ED / ET 做通俗说明，提供「讲解模式」逐步展示。 |
| FR1.4 | 报告模板切换 | 简洁 / 详细两档模板；详细档附解读文本与科普。 |
| FR1.5 | 历史报告管理 | 在历史记录中每份病例一键导出 / 分享（**复用** `historyGateway`）。 |

### F2 不确定性热图 / 可信 AI

| 编号 | 功能 | 说明 |
|---|---|---|
| FR2.1 | 概率保留与熵计算 | 修改 `processMultiClassOutput` 使其同时返回 4 类 softmax 概率张量（64³×4），新增 `computeEntropy` 逐体素算信息熵 `H = -Σ p·log(p)`。熵越高 = 模型越拿不准。 |
| FR2.2 | MPR 热力叠加 | 在 `blend.ts` 的 `renderSlicePixels` 增加不确定性叠加分支（复用现有混色机制），并在 `viewerStore` 加 `showUncertainty` 开关 + 图例。 |
| FR2.3 | 报告内不确定性图 | PDF 报告附一张不确定性热图缩略（高熵区标红），呼应"可信 AI"卖点。 |

> **关键可行性**：前期后处理 `softmax4` 已算出 4 类概率，`processMultiClassOutput` 仅取 argmax 把概率丢弃（见 `postprocess.ts:32-44`）。因此 F2 是**前端后处理改造，几乎不用重训模型**。

### F3 APP 化与导出适配

| 编号 | 功能 | 说明 |
|---|---|---|
| FR3.1 | Capacitor 原生壳 | 新增 `@capacitor/core` / `cli` / `android` / `ios` 依赖，生成 `capacitor.config.ts`（`webDir: dist`），`cap add` + `sync` + `open` 打包。 |
| FR3.2 | 原生文件/分享适配 | 现有 `folderHandle.ts` 用浏览器 File System Access API 写用户文件夹，原生壳 WebView 不支持；改为 `@capacitor/filesystem` 或 `@capacitor/share`。**尽早验证**。 |

## 4. 非功能需求

- **NF1 离线优先 / 隐私**：分割、熵计算、报告生成全在端内完成，数据不出设备，可作"隐私合规"卖点。
- **NF2 移动端性能**：熵计算约 64³×4 ≈ 100 万次运算，前端可接受；建议 INT8 量化 + 推理耗时基准（对比 FP32）。
- **NF3 跨平台兼容**：运行于 iOS / Android WebView 与桌面浏览器，UI 保持响应式。
- **NF4 可解释性**：报告解读规则与不确定性来源对用户透明，便于答辩讲解。

## 5. 可行性分析

### 5.1 前期已完成、本期直接复用

离线推理、NIfTI 解析、三平面可视化、量化统计、历史存储、统一推理接口、jspdf 库、屏幕量化面板——均已完成，本期不再投入。

### 5.2 本期新增工作量映射

| 本期需求 | 复用基础 | 需新增 / 修改 |
|---|---|---|
| F2 概率图 | `postprocess.ts` softmax4 已算，但被丢弃 | 后处理同时返回概率张量 + `computeEntropy` |
| F2 热力叠加 | `blend.ts` `renderSlicePixels` 唯一混色实现 | 加不确定性叠加分支 + `showUncertainty` 开关 + 图例 |
| F1 报告 | `AnalysisReport.tsx` 面板、`statistics.ts`、`jspdf` | 加 PDF 导出 + 解读引擎 + 科普 + 模板 |
| F3 导出 | `historyGateway` 复用 | 文件 / 分享迁移到 Capacitor 原生 API |
| F3 APP 壳 | 无 | 新增 Capacitor 依赖 + `capacitor.config.ts` |

### 5.3 关键发现

- **热图零重训成本**：模型输出 4 通道概率，改后处理即可拿到，无需改模型或训练流程。
- **报告补最后一公里**：量化面板已成型、`jspdf` 已装，PDF 导出是"补尾"而非从零。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **R1 原生壳不支持 File System Access API** | `folderHandle.ts` 依赖浏览器 API，WebView 无此能力（对应 FR3.2） | 改用 `@capacitor/filesystem` / `@capacitor/share`，**阶段0 验证** |
| **R2 iOS 打包门槛** | 需 Mac + 开发者账号出 iOS 包 | 至少交付 Android debug APK；iOS 仅说明流程 |
| **R3 概率张量内存** | 64³×4×4B ≈ 4MB，可接受 | 在 64³ 分辨率算熵并叠加，不强行上采样到原始分辨率 |
| **R4 工作量过载** | 两功能 + APP 化可能做不深 | F1 + F2 已是最精简组合，不建议再堆第 3 个创新点 |

## 8. 结论

前期移动端网页（离线分割、三平面可视化、量化统计、历史管理）已交付，本期只需在其上做**增量开发**：F1 智能报告、F2 不确定性热图、F3 APP 化与导出适配。其中量化、PDF 库、三平面混色、离线推理均可复用；热图凭"保留已算出的 softmax 概率"近乎零成本获得。两项新功能均落在计算机专业擅长的**工程化 / 可视化 / 人机交互**范畴，易于答辩讲解，适合作为 SRTP 最终产物。
