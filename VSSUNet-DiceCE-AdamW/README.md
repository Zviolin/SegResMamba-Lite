## 二、核心架构

```
输入 [B, 4, 64, 64, 64]
    │
    ▼
┌─────────────────────────────────────────────────┐
│  input_proj: ConvBlock(4→8)                      │
│  输出: [B, 8, 64, 64, 64]                        │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  enc1: ConvBlock + VSSBlock + MaxPool            │
│  输出: [B, 16, 32, 32, 32]  ← skip1              │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  enc2: ConvBlock + VSSBlock + MaxPool            │
│  输出: [B, 32, 16, 16, 16]  ← skip2              │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  bottleneck: ConvBlock + VSSBlock                │
│  输出: [B, 64, 8, 8, 8]                          │
└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  dec2: ConvTranspose3d + Cat + ConvBlock + VSSBlock│

└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  dec1: ConvTranspose3d + Cat + ConvBlock + VSSBlock│

└─────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────┐
│  output_proj: Conv3d(1) → [B, 4, 64, 64, 64]    │
└─────────────────────────────────────────────────┘
```

## 三、核心模块: VSSBlock

```
VSSBlock = Vision State Space Block (卷积近似)

输入 x ──────────────────────────────────────┐
    │                                        │
    ▼                                        │
深度可分离卷积 (Conv3d, k=3, groups=C)        │
    │                                        │
    ▼                                        │
BatchNorm3d → SiLU                            │
    │                                        │
    ▼                                        │
门控卷积 (Conv3d, k=1) → chunk → sigmoid      │
    │                                        │
    ├──→ g1 = sigmoid(gate[:, :C])            │
    └──→ g2 = sigmoid(gate[:, C:])            │
    │                                        │
    ▼                                        │
门控融合: out = output_conv(x) * g1           │
         + x * (1 - g2)                       │
    │                                        │
    ▼────────────────────────────────────────(+) ← 残差
输出

特点:
- 门控机制: 类似 LSTM，选择性传递信息
- 深度可分离卷积: 参数高效
- 双门控: g1 控制新信息，g2 控制旧信息
- 注意: 这是卷积近似，不是真正的 SSM/Mamba
```

## 六、实验结果

| 指标 | WT | TC | ET |
|------|------|------|------|
| **全局 Dice** | 0.9106 | 0.8710 | 0.8344 |
| **全局 HD95 (mm)** | 6.30 | 6.89 | 4.69 |
| **LW Dice WT** | 0.6692 | 0.7543 | 0.6901 |
| **LW HD95 WT (mm)** | 5.30 | 5.88 | 5.80 |

### 结果分析

- **参数量最小**: 0.19M，所有模型中最轻量
- **LW HD95 最稳定**: 病灶级别边界重建最好
- **全局 Dice 略低**: 相比其他模型，整体分割精度稍弱
- **显存占用最低**: ~2GB，适合低显存设备

## 九、VSSBlock vs 真正 Mamba

| 对比项 | VSSBlock | 真正 Mamba (mamba_ssm) |
|--------|----------|----------------------|
| **实现方式** | 深度可分离卷积 + 门控 | State Space Model |
| **序列建模** | 无 (局部卷积) | 有 (全局序列) |
| **复杂度** | O(n) 卷积 | O(n) SSM |
| **参数量** | 极少 | 较多 |
| **长距离依赖** | 有限 | 强 |
| **硬件要求** | 无特殊要求 | 需要 CUDA + mamba_ssm |

## 十、定位与意义

VSSUNet 在本项目中作为 **最轻量级基线**：

1. **参数量极小**: 0.19M，资源受限场景的首选
2. **VSSBlock 探索**: 验证卷积近似 Mamba 的可行性
3. **LW HD95 稳定**: 病灶边界重建能力突出
4. **对比参照**: 与真正 Mamba 模型对比，展示近似方法的差距
